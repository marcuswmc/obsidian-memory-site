# Obsidian Memory · landing page

Landing page for [Obsidian Memory](https://github.com/marcuswmc/obsidian-memory-plugin), an open-source plugin that gives Claude Code persistent memory.

Static site (HTML, CSS and JS, no build step). To run it locally:

```bash
python3 -m http.server 4173
```

On Vercel: import the repository with the **Other** framework preset, no build command, and the root as the output directory.
