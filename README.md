# Obsidian Memory · landing page

Landing page do [Obsidian Memory](https://github.com/marcuswmc/obsidian-memory-plugin), plugin open source que dá memória persistente ao Claude Code.

Site estático (HTML, CSS e JS, sem build). Para rodar localmente:

```bash
python3 -m http.server 4173
```

Na Vercel: importe o repositório, framework **Other**, sem comando de build e com o diretório de saída na raiz.
